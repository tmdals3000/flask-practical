## 폴더 설명

- `app.py` — 목록/추가(`/`), 완료 토글(`/toggle/<id>`), 삭제(`/delete/<id>`), 수정(`/edit/<id>`)
- `templates/` — `base.html`(공통 틀), `index.html`(목록), `edit.html`(수정 화면)
- `static/style.css` — 화면 꾸밈
- 데이터는 SQLite(`instance/todo.db`, 저장소에 올리지 않음)에 저장됩니다.

## 실행 방법

```
cd HW3
flask --debug run
```
